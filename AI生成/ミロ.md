# ミロ（AI生成・非正史）

- **時代**：教国アルバ期
- **出身・人種**：ペルキ人（男）
- **立場**：アルバ神学校・高等部 **カリキュラムC**（B の不満の受け口・処分）に落とされた生徒
- **年齢**：19

## 人物

- B で綿花畑に割り当てられ、口答えが多かった。仲間の不満を代わりに言ってやるうちに、**目立つ不満分子**として C に回された。
- C は、B の大多数に「ああはなりたくない」と思わせるための見せしめでもある。ミロ自身、自分がそういう役だと薄々分かっている。
- 不思議と明るい。「俺が落ちたぶん、あいつらは落ちんで済む」と笑う。
- 奴隷頭ハインツ・グラーフは、C に送った生徒の名前を帳面に書き写している。**ミロの名は、そのいちばん新しい行にある**。

## 卓での使いどころ

- 神学校編で PC が**救出するかどうか**を迫られる対象。
- C の実態をどこまで描くかは卓のトーン次第。AI からは、**暴力描写より「見せしめとして置かれている」ことの残酷さ**を軸にする案を出しておく。

## 正史との接点・リスク

- 接点：アルバ神学校.md（C＝B の不満の受け口・処分、約5%、B の待遇差と下への転落の恐怖）。
- 足し算：人物そのもの。C の具体的な処遇は、正史の記述を超えて書かないようにしている。
