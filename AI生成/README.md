# AI生成/ — Claude が考えたキャラクター置き場（非正史）

**ここは正史ではない。** 語り部の依頼で、書記（Claude）が既存資料を読んだうえで**勝手に考えた**人物の置き場。

## 取り扱い

1. **非正史。** `stories/` `world/` `characters/` と同じ重みを持たない。食い違ったら常に正史が勝つ。
2. **本編作業の根拠にしない。** 「AI生成にこう書いてあったから」で正史を動かさない。
3. **正史へ引き上げられるのは、語り部が指示したときだけ。** 採用・改変・ボツは語り部が決める。
4. 各ファイル末尾の **「正史との接点・リスク」** に、どこが既存設定に乗っていて、どこが勝手な足し算かを書いてある。
   引き上げるときはまずそこを見る。

## 作り方の方針

- 既存の命名規則に従う：**◯ー✕型＝中間地帯（アルバ）出身／「プ」始まり＝ペルキ人（南）／姓の「ベル」＝ベル地方（北）**。
- 魔女の定義（**不死＝ガイヤに罰せられた者。魔力の有無は条件ではない**）を守る。
  ※**セブンズ以外の魔女が存在するか、新たな魔女が生まれるかは正史で未確定**。ここの魔女はその「もしも」として置いている。
- 魔女には通り名（他称）とキルカウント（メタ）の欄を付ける。
- 「見かけと実情のずれ」「善意が檻になる」「事故が後から聖別される」など、正史の反復モチーフに沿わせる。
- TRPG で使いやすいよう、各人に **卓での使いどころ** を付ける。
